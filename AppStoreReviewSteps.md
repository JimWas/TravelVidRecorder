App Review Steps (IAP)

1. Launch the app.
2. Tap the mode selector on the main screen.
3. Select any premium mode (Video Playback, Fake Call, Flappy Bird, Bitcoin Price, Calculator).
4. The TravelVid Premium paywall appears with the subscription option and Restore Purchases.

Notes
- The paywall is also reachable from the main screen using the “Go Premium” button.
